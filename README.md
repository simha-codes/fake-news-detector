# fake-news-detector

A simple yet powerful **Fake News Detection** web application built with **Python**, **scikit-learn**, and **Streamlit**.  

The model uses **TF-IDF vectorization** + **Logistic Regression** to classify news articles as **Real** or **Fake** with high accuracy (~98%).

---

## Features

- Clean and preprocess news text (remove URLs, punctuation, numbers, etc.)
- Train a Logistic Regression model on real + fake news dataset
- Interactive web interface using Streamlit
- Real-time prediction when you paste any news article
- Easy to run locally
